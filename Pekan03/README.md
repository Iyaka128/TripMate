# TripMate — Pekan 3: JavaScript, DOM & Event

## Tujuan
Menambahkan interaksi sederhana pada halaman TripMate dengan JavaScript.

## Fitur
1. Pencarian destinasi menggunakan event `input`.
2. Menampilkan/menyembunyikan detail destinasi menggunakan event `click`.
3. Memilih elemen HTML dengan `querySelector` dan `querySelectorAll`.
4. Mengubah konten dengan `textContent` dan mengatur visibilitas dengan `hidden`.

## Cara menjalankan
Buka `index.html` langsung di browser. Tidak membutuhkan PHP atau API.

## File
- `index.html`: struktur halaman.
- `style.css`: tampilan TripMate.
- `script.js`: DOM manipulation dan event handling.

## Uji coba
- Ketik `Bali` pada kolom pencarian; hanya kartu Bali yang tampil.
- Hapus kata pencarian; tiga destinasi tampil kembali.
- Klik `Lihat detail` pada kartu; penjelasan muncul.
- Klik `Tutup detail`; penjelasan disembunyikan kembali.
